# Number Guessing Game

This is a small number guessing game I made in Java while learning. The computer picks a random number and you have to guess it.

You can choose a level before starting. Each level has a different number range and a limited number of attempts. After every guess, the game tells you if your number is too high or too low.

## How to run

1. Download or clone this repo
2. Open the folder in terminal
3. Compile: `javac Main.java`
4. Run: `java Main`

## What I used

Scanner, Random, loops, if-else and methods.
