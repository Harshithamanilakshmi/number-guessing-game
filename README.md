# Number Guessing Game

A small number guessing game I made in Java while learning. The computer picks a random number and you try to guess it.

You choose a level first:
- Easy: 1 to 50, 10 attempts
- Medium: 1 to 100, 7 attempts
- Hard: 1 to 200, 5 attempts

After every guess it says if your number is too high or too low. At the end of each round it shows your wins and losses and asks if you want to play again.

## How to run

1. Download this repo
2. Open the folder in terminal
3. Run `javac Main.java`
4. Run `java Main`

Made using Scanner, Random, loops, if-else and methods.
